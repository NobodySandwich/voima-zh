## 安装指南

### 1. 下载
[点击此处以下载最新版本的压缩包](https://github.com/NobodySandwich/voima-zh/releases) 

### 2. 安装
1.  解压下载的压缩包。
2.  将整个 VOIMA_ZH 文件夹复制到 **VOIMA 游戏的根目录**下。

### 3. 启动
*   **请勿直接运行原版的 VOIMA.exe**，否则启动的是英文原版。
*   正确方式是双击运行 VOIMA_ZH 文件夹内的 **VOIMA_ZH.exe** 以启动有汉化的游戏。

### 4. 卸载
直接删除 VOIMA_ZH 文件夹即可。

## 汉化内容DIY

如果你想参与翻译修正或改成你喜欢的翻译：

1.  进入 VOIMA_ZH 插件目录。
2.  双击打开 **点我修改汉化.html**。
3.  在浏览器中加载并编辑 translations.tsv 文件。
4.  保存tsv并覆盖原文件。
